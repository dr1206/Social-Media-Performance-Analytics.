# Social Media Performance & Marketing Analytics

## Project Overview
This project analyzes social media performance using Power BI. It explores engagement metrics, content performance, platform trends, and audience insights through an interactive three-page dashboard.

## Objectives
- Compare social media platform performance.
- Identify content types that generate higher engagement.
- Analyze engagement trends over time.
- Understand the impact of sentiment and content characteristics.
- Explore posting patterns and influencer performance.
- Compare verified and non-verified accounts.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

## Dashboard Pages

### 1. Social Media Overview
- Total Posts, Likes, Comments, Views and Engagement
- Engagement by Platform
- Posts by Platform
- Engagement Trends Over Time
- Posts by Content Type
- Engagement by Category

### 2. Content Performance Analysis
- Engagement by Content Type
- Average Engagement Rate by Content Type
- Sentiment Distribution
- Engagement by Sentiment
- Engagement vs Content Length
- Hashtag Count vs Engagement

### 3. Audience & Posting Insights
- Engagement by Hour of Day
- Engagement by Day of Week
- Engagement by Influencer Tier
- Platform and Influencer Tier Performance
